# Manuscript fonts

Unmodified fonts distributed with TeX Live:

- `yswab.otf`: Schwabacher by Yannis Haralambous; OpenType conversion by
  Daniel Flipo (yfonts-otf). SIL Open Font License 1.1, see OFL.txt and
  yfonts-README.md.
- `lmroman10-*.otf`: Latin Modern by Bogusław Jackowski and Janusz M. Nowacki.
  GUST Font License, see GUST-FONT-LICENSE.txt.

The vector woodcut in `assets/img/danse-macabre.svg` comes from the supplied
thesis source: Michael Wolgemut, *Danse macabre*, Nuremberg Chronicle (1493).
